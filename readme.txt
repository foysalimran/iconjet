Lightweight SVG icons and social icons for Gutenberg, Elementor, and any page builder. 100% free.

== Description ==

Easy Icons gives you a large library of modern SVG icons and ready-made social media icons that work everywhere on your WordPress site: in the block editor, in Elementor, and in any other page builder through shortcodes.

Every feature is free. There is no Pro version and nothing is locked.

= Why Easy Icons is different =

* **Only the icons you use are loaded.** Icons are output as inline SVG. No icon font files, no extra CSS loaded on every page.
* **One plugin for every editor.** Gutenberg blocks, Elementor's built-in Icon Library, and shortcodes for every other builder. No need for a separate icon plugin per builder.
* **Social icons included.** A ready-made Social Icons block and shortcode with official brand colors, so you don't need a second plugin for social links.

= Works with =

* **Gutenberg (Block Editor)** – Icon block and Social Icons block
* **Elementor** – All icon packs added directly to Elementor's built-in Icon Library, so they work in every Elementor widget that has an icon option
* **Any other builder** – Divi, Beaver Builder, Bricks, Oxygen, WPBakery, the Classic Editor and widgets, using shortcodes

= Icon packs included =

* Lucide
* Tabler Icons
* Phosphor Icons
* Bootstrap Icons
* Material Symbols
* Simple Icons (brand and social logos)
* Font Awesome Free (block editor and shortcodes only, since Elementor already includes it)

Turn any pack on or off from the settings page.

= Social icons =

* 60+ social platforms ready to use: Facebook, X, Instagram, LinkedIn, YouTube, TikTok, WhatsApp, Telegram, Pinterest, Threads, Discord, GitHub and more
* Official brand colors with one click, or your own colors
* Shapes: circle, square, rounded, or icon only
* Size, spacing and hover color controls
* Open links in a new tab and add rel="nofollow" if needed

= Icon features =

* Size, color, background, padding, border radius and rotation
* Add a link to any icon
* Fast icon search with categories and recently used icons
* Upload your own SVG icons (sanitized for security, administrators only)
* Accessibility built in: aria-label for linked icons, aria-hidden for decorative icons
* Translation ready and RTL supported

= Shortcodes =

Single icon:

`[easyicons name="lucide:heart" size="32" color="#e11d48"]`

Icon with link:

`[easyicons name="tabler:mail" size="24" link="mailto:hello@example.com" label="Email us"]`

Social icons:

`[easyicons_social facebook="https://facebook.com/yourpage" x="https://x.com/yourname" instagram="https://instagram.com/yourname" style="circle" brand_colors="yes" size="28"]`

Not sure about the syntax? Use the built-in Shortcode Generator under **Easy Icons → Shortcode Generator**, pick your icons, and copy the shortcode.

== Installation ==

1. Go to **Plugins → Add New** and search for "Easy Icons".
2. Click **Install Now**, then **Activate**.
3. Go to **Easy Icons → Settings** to choose which icon packs to enable.
4. Use the icons:
   * Block editor: add the **Icon** or **Social Icons** block.
   * Elementor: open any icon control and choose **Icon Library**. The new packs appear in the sidebar.
   * Other builders: paste a shortcode into a text, code or shortcode module.

== Frequently Asked Questions ==

= Is it really free? =

Yes. Every feature and every icon pack is free. There is no Pro version.

= Does it work with Divi, Bricks or Beaver Builder? =

Yes, through shortcodes. Add a text or shortcode module and paste the shortcode. The Shortcode Generator makes this easy.

= Will it slow down my site? =

No. Icons are inline SVG and only the icons used on a page are output. No icon font files are loaded.

= Does it conflict with Elementor's Font Awesome icons? =

No. Easy Icons adds new packs to Elementor's Icon Library and leaves the built-in Font Awesome icons untouched.

= Can I upload my own icons? =

Yes. Administrators can upload SVG files. Every file is sanitized before it is saved.

= What happens to my icons if I deactivate the plugin? =

Icons added with the Icon and Social Icons blocks are saved as SVG in your content and stay visible. Shortcodes and Elementor icons from Easy Icons packs will stop displaying until the plugin is active again.
